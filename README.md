## 🚀 Featured Projects

### 🌙 Nur Çeşmesi — AI-Powered Islamic Q&A App
`Flutter` `Android` `iOS` `Python` `RAG` `LLM API` `Oracle Cloud`

Being taken from idea to **Google Play** end-to-end.
- Answers questions using the Risale-i Nur collection as its knowledge source and explains ideas in plain language
- **RAG** backend: text indexing, semantic search and LLM integration, running 24/7 on **Oracle Cloud**
- Offline reader with dictionary, text & photo Q&A, voice chat and a Quran audio player with offline downloads

### 🎬 [Sinevo](https://github.com/Furkn17/sinevo) — Movie Discovery App
`Flutter` `Dart` `Material Design` `Shared Preferences`

*"Filmini Seç, Anını Yaşa."* — a dark, cinematic movie experience.
- Discovery, search, trending and movie detail screens with reusable custom widgets
- Favorites, watchlist and rating interfaces
- Login & register with form validation; passwords hashed with **SHA-256**, never stored in plain text

### 🧠 [QueazyApp](https://github.com/Furkn17/QueazyApp) — Vocabulary Learning App
`Flutter` `Dart` `SQLite`

Memorise words quickly and effectively.
- Create your own word lists and study them with flashcards
- Multiple-choice quiz mode
- All data stored locally with **SQLite**
